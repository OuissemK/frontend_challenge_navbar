# Responsive Burger Navbar

A modern responsive navigation challenge featuring a lateral sidebar transforming into a top navigation bar on tablet and mobile.

This project focuses on layout restructuring, off-canvas interaction, responsive behavior, and clean UI architecture.

---

## 📂 Project Structure

### 01 — Off Canvas Navigation
- Lateral sidebar (desktop)
- Responsive top bar (tablet & mobile)
- Burger menu toggle (open / close states)
- Off-canvas sliding panel
- Native accordion using `<details>` / `<summary>`
- Custom plus/minus icons with pseudo-elements
- Fully responsive layout restructuring

---

## 📱 Responsive Behavior

- **Desktop**
  - Fixed lateral sidebar
  - Vertical delivery text (writing-mode)
  - Icons aligned bottom
  - Off-canvas slides from right

- **Tablet & Mobile (≤1024px)**
  - Sidebar becomes top navigation bar
  - Horizontal layout using CSS Grid
  - Delivery text switches to horizontal mode
  - Off-canvas slides under the top bar

---

## 🎯 Objectives

- Practice advanced CSS Grid layout restructuring
- Convert sidebar → top bar responsively
- Manage UI states with JavaScript
- Improve layout logic and positioning
- Build clean, scalable component architecture

---

## 🛠️ Technologies

- HTML5
- CSS3 (Grid, Flexbox, writing-mode)
- JavaScript (DOM manipulation)
- CSS variables (design tokens)

---

## 📌 Notes

This project is part of my navigation-focused frontend challenge series.

The marquee animation will be refined later using JavaScript.

02 — Marquee Animation

	•	Infinite loop using duplicated content

03 — Fullscreen Menu
